# 수면 지표를 활용한 신체활동 예측: 스마트워치를 활용한 탐색적 연구

## 1. 프로젝트 개요

### 목적

- 스마트워치의 객관적인 수면 지표와 개인이 자각하는 신체·기분·수면 상태 간의 관계 분석
- 수면 지표를 활용한 다음 날 신체활동 예측 가능성 탐색
- 근로자의 신체적·정신적 상태 파악과 안전사고 예방에 활용할 수 있는 생체 지표 탐색

### 진행 기간
**[2024.03 ~ 2024.12]**

### 공동 수행 범위

- **학부생 2명 공동 수행:** 설문 설계, 데이터 수집·전처리, 회귀모델 학습·비교
- **대학원생들과 공동 분석:** 수면·운동 지표 및 설문 응답에 대한 상관분석

## 2. 프로젝트 핵심

- **직접 데이터 수집:** 갤럭시 워치6 측정과 자체 설계 설문 3종을 병행해 객관적·주관적 상태 기록
- **지표 간 관계 분석:** 수면·운동 지표와 설문 응답의 피어슨 상관분석
- **회귀모델 비교·평가:** Random Forest·XGBoost·LightGBM·KNN 4종 실험 및 수면 점수 예측 성능 평가

## 3. 주요 결과

| 구분 | 주요 결과 |
| --- | --- |
| 수면 지표·주관적 상태 | 수면 점수와 주관적 수면 상태 간 **r = 0.817**, `p < 0.01` |
| 수면·운동 지표 | 수면 점수와 체중 조절 심박수 구간의 운동 비율 간 **r = 0.628**, `p < 0.007` |
| 수면 점수 예측 | KNN 교차검증 평균 RMSE **12.89**, 테스트 RMSE **약 11.71** |

## 4. 회고

- **아쉬운 점:** 개인화 예측 모델의 학습과 검증에 충분한 규모의 데이터를 직접 확보하지 못한 점이 아쉬웠습니다.
- **대응:** 직접 수집한 데이터로 수면·운동 지표의 상관관계를 탐색하고, 모델링에는 공개 데이터와 오픈소스 코드를 활용했습니다.
- **다음 목표:** 개인의 수면·운동 데이터를 장기간 축적해, 개인 특성을 반영한 예측 모델을 학습하고 평가해 보고 싶습니다.
