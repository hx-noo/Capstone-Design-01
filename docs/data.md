## 데이터 전처리

### 1. 측정값·설문 응답 정리

- 워치에서 수집한 수면·운동 지표를 날짜별 표로 정리
- 수면 후·운동 전후의 설문 응답을 정리하고 같은 날짜의 측정 지표와 비교
- 수면 시간, 회복 정도, 심박수 및 운동 지표와 주관적 상태의 관계 분석에 활용

### 2. 시간 데이터 변환

- `pd.to_datetime()`으로 시작·종료 시각을 날짜·시간 형식으로 변환
- `end_time - start_time`으로 각 수면 구간의 지속 시간 계산
- `.dt.total_seconds()`로 지속 시간을 초 단위 수치로 변환
- 모델 입력용 `Time in bed`의 `시간:분` 문자열을 `시간 + 분 / 60`으로 변환해 `Time in bed (hours)` 생성

### 3. 수면 단계 매핑·필터링

문자열 수면 단계를 코드로 매핑하고, 특정 단계의 데이터만 추출할 수 있도록 처리했습니다.

| 수면 단계 | 매핑 코드 |
| --- | --- |
| Awake | `40001` |
| Light Sleep | `40002` |
| REM Sleep | `40003` |
| Deep Sleep | `40004` |

- `map()`으로 수면 단계 코드를 생성
- `stage_code == 40004` 조건으로 깊은 수면 구간 추출

### 4. 수치 변환·결측값 처리

- **수면 점수:** `str.rstrip('%').astype(float)`로 `%`를 제거하고 `Sleep quality (numeric)`으로 변환
- **수면 단계 데이터:** `dropna()`로 결측값이 포함된 행 제외
- **모델 학습 데이터:** 입력 변수와 예측 대상의 결측값 확인·제외
- **입력 변수 구성:** 수면 시간·심박수·걸음 수를 모델 입력으로 설정
