# 분석·모델링 및 결과

[프로젝트 요약으로 돌아가기](../README.md)

## 1. 분석 목적

직접 수집한 수면·운동 지표와 주관적 상태의 관계를 탐색하고, 공개 데이터를 활용한 회귀모델로 수면 점수를 예측했습니다.

### 탐색적 분석·상관분석

수면 시간·회복 정도·설문 응답과 운동 시간·심박수·칼로리를 표와 그래프로 비교하고, 지표 간 관계를 피어슨 상관분석으로 분석했습니다.

- **분석 대상:** 워치 수면·운동 지표와 주관적인 신체·기분·수면 상태
- **방법:** 피어슨 상관분석
- **논문의 유의성 기준:** 양측 검증, `p < 0.01`

상관분석은 대학원생들과 함께 수행했습니다.

## 2. 모델 구성

수면 점수 예측을 위해 다음 4종의 회귀모델을 실험했습니다.

| 모델 | 설정·활용 내용 |
| --- | --- |
| Random Forest | `n_estimators=550`, `random_state=82` |
| XGBoost | `max_depth=10` |
| LightGBM | `max_depth=5` |
| KNN Regressor | 교차검증·테스트 데이터 평가 및 수면 점수 예측 |

## 3. 평가 방법

- **R²:** Random Forest·XGBoost 등의 예측 결과 평가에 사용
- **RMSE:** KNN의 교차검증 및 테스트 데이터 예측 오차 평가에 사용

## 4. 모델 비교 결과

### KNN 평가 결과

| 평가 항목 | 결과 |
| --- | --- |
| 교차검증 평균 RMSE | **12.89** |
| 테스트 데이터 RMSE | **약 11.71** |

### 최종 모델 선정

**KNN Regressor를 최종 수면 점수 예측 모델로 채택했습니다.**

- **선정 이유:** 당시 실험에서 모델별 예측 성능을 검토해 KNN Regressor를 선택했습니다.
- **예측 대상:** 수면 시간·심박수·걸음 수를 입력받아 수면 점수 예측
- **평가 과정:** 교차검증과 테스트 데이터의 RMSE를 산출하고, 별도 입력값에 대한 예측 결과 확인

### 핵심 분석 결과

#### 직접 수집한 데이터의 관계 탐색

- 수면 시간이 길다고 정신 회복 정도가 항상 높아지는 것은 아니라는 관찰 정리
- 서로 다른 수면 상태에서 운동 시간·심박수·소모 칼로리와 설문 응답 비교
- 수면과 운동 수행 상태의 관계를 더 분석하고 예측 모델로 확장하는 방향 설정

#### 워치 측정 지표와 주관적 상태의 관계

논문에서는 수면 점수와 주관적으로 평가한 상태 사이에 다음과 같은 양의 상관관계를 보고했습니다.

| 비교 항목 | 상관계수 r | 유의확률 |
| --- | --- | --- |
| 수면 점수와 신체 상태 | **0.725** | `p < 0.01` |
| 수면 점수와 기분 상태 | **0.685** | `p < 0.01` |
| 수면 점수와 주관적 수면 상태 | **0.817** | `p < 0.01` |

#### 수면 지표와 운동 지표의 관계

- 수면 점수와 **체중 조절 심박수 구간의 운동 비율** 사이에서 양의 상관관계 확인
- 논문 보고값: **r = 0.628, p < 0.007**
- 수면 지표를 다음 날 신체활동과 연결해 탐색할 수 있는 가능성 확인

## 5. 개선 과정

- 직접 수집한 데이터는 수면·운동 지표의 관계 탐색에 활용
- 개인화 모델 학습에 충분한 데이터를 확보하기 어려워, 회귀모델 실험은 공개 데이터와 오픈소스 코드를 활용해 진행
- Random Forest·XGBoost·LightGBM·KNN을 실험하고 모델별 설정을 조정하며 예측 결과 비교
